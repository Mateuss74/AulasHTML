Modelo em caixa, Model Box HTML

Os elementos html são estruturados em um modelo denominado modelbox, que refere-se a característica de um elemento pode conter outros elementos, sendo que cada um possui uma estrutura interna, similar a ideia e uma caixa dentro da outra

Estrutura de um elemento HTML

Todos elementos HTML possuem conteúdo, padding, borda, offset. Sendo a região de conteúo estruturada em três camadas 1) background-color 2) backgrond-image 3) content
