Internet e Web

Diferença entre Internet e Web

A Internet é uma grande rede mundial que conecta computadores e dispositivos. Já a Web é um serviço que funciona dentro da Internet e permite acessar páginas e conteúdos através de navegadores.

História da Internet e da Web

A história da Internet começou com projetos de comunicação entre computadores. Um dos principais marcos foi a ARPANET, criada no final da década de 1960.

Durante os anos seguintes, diferentes redes passaram a utilizar protocolos que permitiam a comunicação entre computadores.

Principais marcos

  1. 1969 - Criação da ARPANET
  2. 1983 - Adoção do protocolo TCP/IP
  3. 1989 - Proposta da World Wide Web
  4. 1991 - Primeira página Web
  5. Década de 1990 - Popularização da Web
  6. Década de 2000 - Crescimento das redes sociais

Características

  • Comunicação mundial
  • Compartilhamento de informações
  • Acesso a páginas Web
  • Serviços online

Alguns conceitos

Internet
Rede mundial que conecta dispositivos.
Web
Sistema de páginas e recursos acessados pela Internet.
HTTP
Protocolo utilizado para comunicação entre navegador e servidor Web.

A Web foi criada por Tim Berners-Lee e utiliza tecnologias como HTML, HTTP e URLs.

Exemplo de fórmula relacionada à Web: H2O

A Web utiliza diferentes tecnologias, incluindo HTML5.

Relato

A evolução da Internet mudou a maneira como as pessoas estudam, trabalham, conversam e acessam informações. Atualmente, a Web faz parte do cotidiano de milhões de pessoas.
