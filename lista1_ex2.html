Protocolo HTTP

O que é HTTP?

HTTP significa HyperText Transfer Protocol. É um protocolo utilizado para a comunicação entre navegadores e servidores na Web.

Quando acessamos um site, o navegador envia uma requisição HTTP para um servidor. O servidor processa a solicitação e devolve uma resposta.

Funcionamento

  1. O usuário digita um endereço no navegador.
  2. O navegador envia uma requisição HTTP.
  3. O servidor recebe a requisição.
  4. O servidor processa a solicitação.
  5. O servidor envia uma resposta.
  6. O navegador apresenta o conteúdo.

Exemplo de Request

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html

Campos do Request

  • GET: método utilizado para solicitar um recurso.
  • /index.html: recurso solicitado.
  • HTTP/1.1: versão do protocolo.
  • Host: servidor que será acessado.
  • User-Agent: identifica o navegador ou cliente.
  • Accept: informa quais tipos de conteúdo o cliente aceita.

Exemplo de Response

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1250

Campos da Response

  • HTTP/1.1: versão do protocolo.
  • 200 OK: código indicando que a solicitação foi realizada com sucesso.
  • Content-Type: tipo de conteúdo enviado.
  • Content-Length: tamanho aproximado do conteúdo.

Códigos HTTP

Alguns códigos HTTP
